# 日常记录 · Daily Tracker

面向学生 / 职场新人的轻量「日常记录 + 自我管理」Web 工具。所有数据**仅保存在浏览器本地（IndexedDB）**，无需登录、无需后端。

> 对应产品策划案：`日常记录软件-策划案.md`（需求规划阶段产出）

## 已实现功能（P1 + P2 全量）

| 模块 | 说明 |
|------|------|
| 🏠 首页 Dashboard | 今日概览：最新体重 / 待办完成度 / 专注 / 习惯打卡，含「今日提醒」横幅 |
| ⚖️ 体重记录 | 录入体重（数值+日期+备注）、趋势曲线、目标线、删除 |
| ✅ 每日待办 | 增删改、完成切换、今日/全部筛选、分类标签 |
| 🍅 番茄钟 | 计时（专注/休息可切）、**绑定具体待办**、自动累计专注时长、环形进度 |
| 🔥 习惯打卡 | 自建习惯、每日一键打卡、连续天数（streak）、删除 |
| 📝 记录 | 心情（多条·emoji 5 级+文字）/ 喝水（快捷杯量）/ 饮食（早午晚加餐）|
| 📅 日历 | 月视图聚合标记（体重/待办/番茄/习惯/心情）、当日明细 |
| 📊 统计 | 体重趋势、近 14 天专注、待办完成率、累计专注、今日习惯 |
| ⚙️ 设置 | 番茄/休息时长、目标体重、数据导出（JSON / CSV） |

## 技术栈

React 18 + Vite + TypeScript · Tailwind CSS · Dexie（IndexedDB）· Zustand · Recharts

## 本地运行

```bash
npm install
npm run dev        # 开发预览 http://localhost:5173
npm run build      # 生产构建到 dist/
npm run preview    # 预览构建产物
```

## 目录结构

```
src/
├─ App.tsx          # 路由 / 响应式布局 / 番茄钟计时循环 / 首次引导
├─ store.ts         # 全局状态（设置 + 持久化番茄钟）
├─ db.ts            # Dexie 本地数据层与 CRUD
├─ types.ts         # 领域类型
├─ utils.ts         # 日期 / 导出工具
└─ pages/           # Dashboard / Weight / Todo / Focus / Calendar / Stats / Settings
```

## 已知边界

- 提醒仅应用内（离开网页即失效），如需离开后推送需后续接浏览器通知（Notification API）。
- 番茄钟计时在页面刷新后会重置（未做后台保活）。
- 暂未做云端同步 / 多账户，数据随浏览器；可通过「设置 → 导出」备份。
- 习惯为「每日打卡 + 连续天数」模型，暂不支持「每周 N 次」目标。

## 数据模型（P2 新增）

- `habits` / `habitCheckIns`：习惯与每日打卡
- `moods`：心情日记（可多条 / 天，emoji 5 级 + 文字）
- `intakes`：喝水（ml）/ 饮食（早午晚加餐 + 文字）
